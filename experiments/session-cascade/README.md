# Session Cascade experiment

A standard-library Python reference for deterministic, explicit, **ephemeral** OmniTag session metadata.

See [RECONSTRUCTED_42.md](RECONSTRUCTED_42.md) for the candidate 42-technique research catalog and provenance boundaries.

Run tests from this directory:

```sh
python -m unittest discover -s tests -v
```

No implicit long-term memory, no automatic external actions, no authority conveyed by symbols. This experiment does not change the public OmniTag grammar.
