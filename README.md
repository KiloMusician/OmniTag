# OmniTag

🌌 **OmniTag is awake again.**

This public repository is a lightweight home for the symbolic / semantic language
experiments behind OmniTag.

It is intentionally **not** the operational control plane for the Greater System.
Infrastructure, private orchestration, credentials, machine state, and repository
authority belong in their actual owning systems.

Think of this repo as the visible constellation chart, not the engine room.

## Current role

During the 2026 organization migration, this personal-namespace repository also acts as
a harmless public continuity marker while private project repositories move into their
new organizational homes.

No secrets. No machine authority. No hidden production state.

```text
symbol != authority
description != execution
presence != proof
map != territory
unknown > guessing
reported != executed
```
